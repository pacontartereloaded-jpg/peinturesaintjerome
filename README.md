# Peinture Saint-Jérôme

Site vitrine d'une équipe de peintres régionaux à Saint-Jérôme, Québec — couvrant la MRC Rivière-du-Nord pour des projets résidentiels, immeubles locatifs et commerciaux.

## Stack
HTML5 + CSS3 + JavaScript vanilla. Aucune dépendance.

## Sections signature
- **Couverture régionale** — 3 zones (centrale / proche / régionale élargie) avec délais d'arrivée
- **Services par catégorie** — 4 catégories (résidentiel int. · résidentiel ext. · immeubles locatifs · commercial léger)
- **MRC stats** — 14 villes, 320+ chantiers, 15 ans, garantie 2 ans
- **Process classique en 6 étapes** — visite → garantie

## Stack visuel
- Palette : bleu profond #1f3a52 / sable #d9cfb8 / brique #a14a36
- Typo : Bricolage Grotesque (display fort) + Source Sans 3 (body)
- Animations : sobres, parallax léger sur hero
